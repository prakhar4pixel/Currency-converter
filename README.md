# **💱 Currency Converter**

A simple JavaScript project that converts currencies in real time — built to sharpen my JavaScript skills.

## 🚀 Getting Started

### Run it locally in two steps:
Pull it remotely with "git clone https://github.com/prakhar4pixel/Currency-converter.git"
Then open index.html in your browser.

## 🛠️ Technologies Used
HTML, CSS, JavaScript — core technologies for the app
APIs — fetches real-time exchange rate data
